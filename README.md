# Exercício prático de Python

Cada arquivo corresponde a uma atividade do PDF:

1. `estruturas_condicao1.py` — condição `if/else` para temperatura.
2. `estruturas_condicao2.py` — classificação por tempo de experiência usando `if/elif/else`.
3. `estruturas_repeticao1.py` — leitura repetida até digitar `0`.
4. `estruturas_repeticao2.py` — laço `for` sobre texto e intervalo de 1 a 10.
5. `funcoes1.py` — função sem parâmetros que imprime uma variável local.
6. `funcoes2.py` — função com parâmetro e comparação sem diferenciar maiúsculas/minúsculas.
7. `calculadora_v2.py` — calculadora com funções de soma, subtração, multiplicação e divisão, validação de divisão por zero e repetição até responder `N`.

Execute qualquer atividade com Python 3, por exemplo: `python calculadora_v2.py`.
